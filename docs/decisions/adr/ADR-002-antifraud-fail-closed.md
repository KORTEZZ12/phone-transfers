# ADR-002. При недоступном антифроде перевод уходит на проверку

Статус: принято. Связано с D-03, TR-20, NFR-08.

## Контекст

Требования к противодействию переводам без согласия клиента не позволяют выполнять переводы без проверки. Антифрод — внешняя система, она бывает недоступна.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Fail-open: пропускать без проверки до порога суммы | Клиенты не ждут | Окно для мошенничества ровно на время сбоя, регуляторный риск |
| Fail-closed: на проверку с автоповтором | Ни одного перевода без проверки | При долгом сбое переводы копятся, клиенты ждут |
| Держать запрос, пока антифрод не ответит | — | Таймауты у клиента, повторы, тот же результат, что и fail-closed, только хуже |

## Решение

Fail-closed. Нет ответа за P-09 — статус REVIEW, проверка повторяется каждые P-10. Клиент видит «На проверке» и может отменить перевод, деньги остаются заблокированными.

## Последствия

- Алерт, если на проверку из-за таймаута уходит больше 5% переводов за 5 мин (NFR-08): длинный сбой видно сразу, а не по жалобам.
- После восстановления антифрод получит накопленные повторы. Повторы идут с паузой и случайным разбросом, чтобы не перегрузить его.
- Срок P-11 ограничивает ожидание: без решения перевод отклоняется, деньги возвращаются.
