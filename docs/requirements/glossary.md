# Глоссарий

| Термин | Значение |
|---|---|
| Перевод | Распоряжение отправителя перевести сумму получателю по номеру телефона |
| Отправитель | Клиент банка, который переводит деньги |
| Получатель | Клиент банка, которому переводят деньги |
| Токен получателя | Результат поиска по номеру: короткоживущая ссылка на найденного клиента. Перевод создаётся по токену, а не по номеру |
| Ключ идемпотентности | Идентификатор попытки перевода. Приложение создаёт его на экране подтверждения. Ключ хранится вместе с переводом всегда, повтор с тем же ключом не создаёт новый перевод |
| Холд | Блокировка суммы на счёте отправителя до решения по переводу |
| Проводка | Запись в леджере: дебет одного счёта и кредит другого на одну сумму |
| Сторно | Обратная проводка, которая исправляет ошибочную. Исходная проводка не меняется |
| Леджер | Учёт счетов, холдов и проводок по двойной записи |
| Антифрод | Внешняя система, которая решает: разрешить, отклонить или отправить на ручную проверку |
| Ручная проверка | Проверка перевода сотрудником службы безопасности |
| Лимит | Максимальная сумма переводов на операцию, в сутки или в месяц |
| Outbox | Таблица событий, которая пишется в той же транзакции, что и статус перевода. Отдельный процесс переносит события в Kafka |
| Событие | Сообщение об изменении статуса перевода для уведомлений и истории операций |
| DLQ | Очередь для событий, которые не удалось обработать после всех повторов |
| Сверка | Проверка, что проводки и выполненные переводы сходятся |
| Повтор запроса | Запрос с тем же ключом идемпотентности. Возвращает уже созданный перевод с заголовком `Idempotent-Replayed`, срока у повтора нет |
| Аренда обработки | Срок P-14, в течение которого перевод ведёт один участник: запрос или регламентная проверка. Повтор в это время получает 409 |
| Relay | Процесс, который переносит события из outbox в Kafka |
| Регламентная проверка | Задание по расписанию: доводит зависшие переводы и снимает холды без активного перевода |
| traceparent | Заголовок W3C Trace Context: по нему находится вся цепочка вызовов одного запроса |
| Problem Details | Формат ошибки по RFC 9457: `type`, `title`, `status`, `detail`, плюс код `code` |
| Курс ЦБ | Официальный курс валюты к рублю, загружается из SOAP-сервиса ЦБ DailyInfo |
