# Антифрод

Внешняя система банка. Проверяет каждый перевод (TR-19), сомнительные отправляет сотруднику на ручную проверку.

## Проверка перевода

`POST /api/v1/checks` — вызывает сервис переводов после холда.

Запрос:

| Поле | Тип | Описание |
|---|---|---|
| transferId | uuid | Ключ идемпотентности проверки: повтор возвращает то же решение |
| occurredAt | date-time | Время создания перевода |
| senderClientId | uuid | Отправитель |
| recipientClientId | uuid | Получатель |
| amount | Money | Сумма и валюта |
| amountRub | string | Рублёвый эквивалент |
| channel | MOBILE | Канал |
| deviceId | string | Из заголовка `X-Device-Id` приложения |
| ipAddress | string | IP клиента, который передаёт API-шлюз |

Ответ 200:

| Поле | Значения | Что делает сервис переводов |
|---|---|---|
| decision | ALLOW | CHECKING → POSTING, проводка |
| decision | DENY | CHECKING → REJECTED, причина FRAUD_SUSPECTED, снять холд |
| decision | REVIEW | CHECKING → REVIEW, срок P-11, ждать колбэк |
| decision | SUSPEND | CHECKING → SUSPENDED, срок подтверждения P-20, пуш отправителю с запросом подтверждения (TR-35) |
| caseId | string | Номер кейса ручной проверки, хранится для разбора |

Отказы:

| Ситуация | Что делает сервис переводов |
|---|---|
| Нет ответа за P-09 (2 с), обрыв, 5xx | REVIEW, задача проверки повторяется с паузой, которая растёт до P-10 (5 мин), со случайным разбросом. Без решения антифрода перевод не выполняется (ADR-002) |
| P-19 отказов подряд | Предохранитель: вместо повторов по каждому переводу — одна проба раз в 10 с. После успешной пробы очередь разбирается не быстрее P-18, старые переводы первыми |
| 4xx | Дефект в запросе: REVIEW, алерт, задача не повторяется. После исправления операционист запускает повторную проверку; срок P-11 продолжает идти |

## Повторная сверка после подтверждения

`POST /api/v1/checks/{transferId}/confirmation` — вызывает сервис переводов задачей после того, как отправитель подтвердил приостановленный перевод (TR-37). Антифрод заново сверяется с базой данных Банка России о переводах без согласия. Идемпотентна по transferId, повторы — как у проверки.

| decision | Что делает сервис переводов |
|---|---|
| ALLOW | CHECKING → POSTING, проводка |
| DELAY | CHECKING → COOLING, `executeAfter` = момент приостановки + P-21, пуш с датой исполнения |

Сверку с базой Банка России выполняет антифрод, сервис переводов к базе напрямую не обращается (допущение A5).

## Решение по ручной проверке

Антифрод вызывает `POST /internal/v1/antifraud/decisions` — контракт в [OpenAPI](../api/openapi.yaml). Взаимный TLS, сертификат антифрода из доверенного списка.

| Ситуация | Ответ сервиса переводов |
|---|---|
| Перевод в REVIEW, решение ALLOW, DENY или SUSPEND | 200, `applied: true` |
| Перевод ещё в CHECKING: решение пришло раньше, чем сервис записал REVIEW | 200, `applied: true`. Решение сохраняется и применяется при переходе в REVIEW |
| Повтор с тем же decisionId | 200 с тем же результатом |
| Перевод уже финальный: отменён отправителем или истёк срок | 200, `applied: false`, текущий статус. Антифрод закрывает кейс |
| Перевод не найден | 404. Антифрод не повторяет, а отправляет кейс на разбор |
