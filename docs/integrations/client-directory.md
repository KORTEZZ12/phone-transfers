# Справочник клиентов

Внешняя система банка: по номеру телефона находит клиента и его основные счета.

## Поиск клиента

`POST /internal/v1/clients/search` — номер в теле, а не в URL, чтобы не попасть в журналы доступа.

Запрос:

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| phone | string, E.164 | да | `+79991234567` |

Ответ 200:

| Поле | Тип | Описание |
|---|---|---|
| clientId | uuid | Идентификатор клиента |
| firstName | string | Имя |
| lastName | string | Фамилия, сервис переводов берёт только первую букву |
| status | ACTIVE, BLOCKED | Заблокированный клиент — как не найденный |
| primaryAccounts | массив | Основные счета: `accountId`, `currency`, `status` |

Ответы и реакция сервиса переводов:

| Ответ | Что делает сервис | Что получает приложение |
|---|---|---|
| 200, клиент ACTIVE | Создаёт токен получателя на P-01, сохраняет сокращённое имя и счета | 200 с токеном |
| 200, клиент BLOCKED | Как не найден: не раскрываем статус чужого клиента | 404 RECIPIENT_NOT_FOUND |
| 200, клиент — сам отправитель | — | 422 SELF_TRANSFER |
| 404 | — | 404 RECIPIENT_NOT_FOUND |
| Таймаут, 5xx | Один повтор, затем отказ | 503 SERVICE_UNAVAILABLE |

## Данные

- Полное имя и фамилия не сохраняются: в токене только «Иван П.» и идентификаторы.
- Токены удаляются регламентной задачей через сутки после истечения ([NFR-09](../requirements/nfr.md)).
- Номер телефона в логах маскируется: `+7 *** ***-45-67`.
