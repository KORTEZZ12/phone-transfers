# Интеграции

Версия 0.2. Сводка всех внешних вызовов сервиса переводов. Подробности — в файле по каждой системе.

| Система | Кто вызывает | Протокол | Таймаут | Повторы | Идемпотентность | Если система недоступна |
|---|---|---|---|---|---|---|
| [Справочник клиентов](client-directory.md) | Сервис переводов | REST, синхронно | 500 мс | 1 повтор | чтение | Поиск возвращает 503 с Retry-After |
| [Леджер](ledger.md) | Сервис переводов | REST, синхронно | 1 с | В запросе — 2 повтора через 100 и 300 мс, дальше регламентная проверка (TR-30) | по transferId | Холд: 503 приложению, повтор с тем же ключом. Проводка: перевод ждёт в POSTING |
| [Антифрод, проверка](antifraud.md) | Сервис переводов | REST, синхронно | 2 с (P-09) | Каждые 5 мин (P-10) | по transferId | Перевод уходит на проверку (TR-20) |
| [Антифрод, решение](antifraud.md#решение-по-ручной-проверке) | Антифрод | REST, колбэк с mTLS | — | Антифрод повторяет до ответа 200 | по decisionId | — |
| Kafka | Relay outbox | Kafka, [AsyncAPI](../api/asyncapi.yaml) | — | Relay повторяет до подтверждения | по eventId у потребителей | События ждут в outbox, переводы не останавливаются |
| [ЦБ РФ, DailyInfo](cbr-dailyinfo.md) | Загрузчик курсов | SOAP 1.1, по расписанию | 10 с | Следующий слот через 30 мин | чтение | Последний загруженный курс и алерт (TR-26) |

Общие правила для всех синхронных вызовов:
- `traceparent` передаётся дальше без изменений, в логах — `transferId` и `traceId`.
- Повторяются только таймауты, обрывы и 5xx. Ответы 4xx не повторяются: это ошибка в запросе, повтор её не исправит.
- Повторы — с экспоненциальной паузой и случайным разбросом, чтобы после сбоя смежная система не получила все повторы одновременно.
